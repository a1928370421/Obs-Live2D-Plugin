# OBS Live2d Plugin

Este plugin está basado en el CubismNativeFrameWork integrado de Live2d.
Permite mostrar modelos de Live2d en pantalla.

# Soporte
* Versión de OBS Studio soportada: 25.0.0+
* Soporte para Cubism3+ (.model3.json .moc3)
* No soporta archivos de movimiento .mtn

# Cómo usar
* Descargar [obs-plugins.zip](https://github.com/a1928370421/Obs-Live2D-Plugin/releases/download/0.2.02/obs-plugins.zip)
* Descomprimir el archivo y colocar `live2d_plugin.dll` en `obs-plugins/64bit/`
* Ejecutar OBS y añadir la fuente Live2d.
